# プロダクト概要

Claude Code から Azure AI Foundry（Microsoft Foundry）の `gpt-image-2` モデルを呼び出して画像を生成する **Agent Skill** を提供するプロジェクト。ユーザーが Claude Code 上で「画像を生成して」と依頼すると、スキルが自動的に読み込まれ、生成画像をローカルにファイルとして保存する。

> 現状はグリーンフィールド。要件は `gpt-image_specs.md` に定義済みで、実装（`.claude/skills/gpt-image-2/`）はこれから着手する段階。

## コア能力

- テキストプロンプトからの画像生成（Azure OpenAI `images/generations`）
- `size` / `quality` / `output_format` / `background` / `output_compression` / `n` のパラメータ制御
- 生成画像（Base64）のデコードとローカル保存（一意なファイル名・連番対応）
- キーレス（Entra ID）と API キーの両認証経路に対応した安全な認証情報の受け渡し

## 対象ユースケース

- Claude Code での対話中に、簡易な指示だけで画像を生成・保存したい開発者
- 正方形 / 横長 / 縦長、透過 PNG、JPEG 圧縮などプリセット的な出力を素早く得たいケース

初版では対象外（将来拡張）: 画像編集・マスク・インペインティング、ストリーミング、バッチ／キュー処理、Web UI。

## 価値提案

中心となる設計方針は2点。

1. **モデル（Claude）に API を手書きさせない。** 画像生成ロジックは自己完結したスクリプトに閉じ込め、Claude は `SKILL.md` の手順どおりスクリプトを呼び出すだけにする。これにより再現性と安全性を担保する。
2. **パラメータは CLI 引数 + 妥当なデフォルト値で渡す。** 必須は `--prompt` のみ。その他は検証付きの名前付き引数として公開し、未指定なら推奨デフォルトを適用する。Claude は差分だけを指定すればよい。
